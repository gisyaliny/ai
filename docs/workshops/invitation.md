# Build Your Own Coding Agent — Workshop Invitation

## 中文

还在担心 token 不够用、写代码总被额度打断？让手边的算力多做一点！从合适的本地模型出发，动手打造拥有 Codex / Claude Code 式工作流程的编程助手：读代码、提修改、看差异、跑测试。

这套免费公开 workshop 用 8 个实验，带你在 Windows、Linux 或 macOS 上，从零搭建 VS Code 编程助手，连接本机或远程模型服务，理解工具调用、界面设计，以及 MCP 和 skills 的扩展思路。附可复制代码、完整源码和验收任务，照着做，也学会为什么这样做。

旧显卡也可能运行适合的小型量化模型，具体取决于硬件支持和显存。课程提供三种系统的命令和脚本，Mac Studio、Linux GPU 服务器或 Windows 工作站都可以作为模型主机。本地推理减少对云端 token 额度的依赖，但不是无限算力，也不保证达到商业产品的全部能力。

## English

Still watching your token budget instead of building? Put more of your own compute to work. Build a coding assistant with a Codex- or Claude Code-style workflow: read code, propose changes, review diffs, and run tests.

This free, public workshop walks you through eight hands-on labs building a VS Code coding assistant on Windows, Linux, or macOS, with a same-machine model or a remote server reached through SSH. Learn tool calling, interface design, and extension paths for MCP and skills—with copyable code, full source, and clear checkpoints.

An older supported GPU may also run a suitably small quantized model, depending on VRAM and runtime compatibility; the workshop includes platform-specific commands and scripts for Windows, Linux, and macOS. Local inference reduces reliance on cloud token allowances, but hardware limits and capability differences still apply.
