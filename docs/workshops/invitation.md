# Build Your Own Coding Agent — Workshop Invitation

## 中文

还在担心 token 不够用、写代码总被额度打断？让手边的算力多做一点！从合适的本地模型出发，动手打造拥有 Codex / Claude Code 式工作流程的编程助手：读代码、提修改、看差异、跑测试。

这套免费公开 workshop 用 8 个实验，带你连接 Windows VS Code 与 Mac Studio，理解工具调用、界面设计，以及 MCP 和 skills 的扩展思路。附可复制代码、完整源码和验收任务，照着做，也学会为什么这样做。

旧显卡也可能运行适合的小型量化模型，具体取决于硬件支持和显存；本课程的实操后端使用 Mac Studio。本地推理减少对云端 token 额度的依赖，但不是无限算力，也不保证达到商业产品的全部能力。

## English

Still watching your token budget instead of building? Put more of your own compute to work. Build a coding assistant with a Codex- or Claude Code-style workflow: read code, propose changes, review diffs, and run tests.

This free, public workshop walks you through eight hands-on labs connecting Windows VS Code to a Mac Studio model server. Learn tool calling, interface design, and extension paths for MCP and skills—with copyable code, full source, and clear checkpoints.

An older supported GPU may also run a suitably small quantized model, depending on VRAM and runtime compatibility; this workshop uses Mac Studio. Local inference reduces reliance on cloud token allowances, but hardware limits and capability differences still apply.
