Materials and facilitation#

Download the shared fixture kit. The offline scripts have executable assertions; live model and vendor-client exercises require your own environment. Work in pairs: one person executes, the other checks the evidence. Plan breaks between tracks rather than attempting every workshop in one sitting.

Knowledge Quiz#

Does a successful documentation build prove every live exercise works?

AnswerNo. Offline tests, documentation rendering and live service checks are different evidence.

What belongs in evidence.md?

AnswerVersions, observed results, failures and limitations, without credentials or personal data.
